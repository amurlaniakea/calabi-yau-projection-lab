Core equations / Ecuaciones clave



Orthogonal projection R^n -> R^2

π(x)=(⟨x,u1⟩,⟨x,u2⟩)

The basis u1,u2 is a chosen 2-plane. Changing the seed changes the camera, not the object.




Clifford torus in R^4

T(u,v)=(rcosu,rsinu,rcosv,rsinv),r=1/2

For r=1/sqrt(2), T is S^1 x S^1 embedded in the unit 3-sphere S^3.




Fermat patch

z1^n+z2^n=1

Complex curve in C^2, real 2D surface in R^4, with n^2 phase patches. Not a full Calabi-Yau threefold.




Quintic Calabi-Yau threefold

∑i=04Zi5=0,X⊂CP4

Complex dimension 3, real dimension 6. Exact invariants: h11=1, h21=101, chi=-200.




Quintic affine chart Z4=1

z05+z15+z25+z35+1=0

Local chart in R^8. z3 solved by 5th root. Branch 0-4. Residual checked. Not global, no metric.




Euler characteristic from Hodge numbers

χ=∑p,q(-1)p+qhp,q

The Python topology module computes these with exact integers for supported Fermat families.




PSM note: future metric layer

(ω+i∂∂¯φ)3=efω3

Complex Monge-Ampere type equation behind Ricci-flat CY metrics. Documented as future layer, not implemented in the zero-dependency core.
