Core equations / Ecuaciones clave

Orthogonal projection R^n -> R^2

π(x)=(⟨x,u1⟩,⟨x,u2⟩)

The basis u1,u2 is a chosen 2-plane. Changing the seed changes the camera, not the object.

Clifford torus in R^4

T(u,v)=(rcosu,rsinu,rcosv,rsinv),r=1/2

For r=1/sqrt(2), T is S^1 x S^1 embedded in the unit 3-sphere S^3.

Fermat patch

z1^n+z2^n=1

This is a complex curve in C^2, real 2D surface in R^4. It has n^2 phase patches. It is not a full Calabi-Yau threefold.

Quintic Calabi-Yau threefold

∑i=04Zi5=0,X⊂CP4

Complex dimension 3, real dimension 6. Known exact invariants: h^{1,1}=1, h^{2,1}=101, χ=-200.

Euler characteristic from Hodge numbers

χ=∑p,q(-1)p+qhp,q

The Python topology module computes these values with exact integers for supported Fermat families.

PSM note: pseudo-spectral method / future metric layer

(ω+i∂∂¯φ)3=efω3

This is the type of complex Monge-Ampere equation behind Ricci-flat Calabi-Yau metrics. It is documented here as a future scientific layer, not implemented in the zero-dependency core.
